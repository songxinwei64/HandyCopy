# HandyCopy ✨

**HandyCopy** is a clean and lightweight web tool for quickly copying emojis, fancy fonts, and text styles.

It is designed for users who want to create SNS captions, bios, messages, and aesthetic text without logging in or dealing with ads.

👉 Live Demo: https://handy-copy-nine.vercel.app/

---

## 📌 Overview

Many emoji and fancy font websites are slow, cluttered with ads, or require unnecessary steps.

HandyCopy focuses on a simple experience:

> Open → Choose → Copy → Paste

No login.  
No ads.  
No unnecessary features.  
Just fast copy & paste.

---

## 🚀 Features

### 📚 Emoji Library
- Browse emojis by category
- Search and copy emojis instantly
- Clean grid-based layout for quick selection

### 🕘 Recently Used
- Automatically saves recently copied emojis
- Stored locally in the browser using LocalStorage
- No user data is sent to a server

### ✍️ Fancy Fonts
- Convert normal text into Unicode-based fancy styles
- Useful for SNS bios, captions, usernames, and messages

### 📋 One-click Copy
- Copy emojis or styled text directly to clipboard
- Simple feedback after copying

### 📱 Responsive Design
- Optimized for mobile, tablet, and desktop
- Smooth user experience across different screen sizes

### 🔒 Privacy-friendly
- No login required
- No backend
- No personal data collection
